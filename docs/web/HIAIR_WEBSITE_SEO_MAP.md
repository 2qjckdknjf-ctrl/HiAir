## Implementation controls

- One canonical URL and one H1 per indexable page.
- Unique title and description per sitemap URL.
- Open Graph and Twitter metadata retained.
- Homepage schema contains no ratings, reviews, or user-count claims.
- FAQ schema matches visible FAQ content.
- Sitemap remains generator-owned and has 13 useful URLs.
- `robots.txt` continues to advertise `https://hiair.io/sitemap.xml`.
- Internal links, sitemap membership, stale launch copy, and store truth are CI-validated.
- Existing original content pages are retained; proposed keyword pages were not added because a thin route would not improve users or search quality.

## Future content candidates

`/best-time-to-go-outside/`, `/air-quality-for-walking/`, and `/pollen-app/` should only be considered after original briefs, source evidence, and distinct user value exist. They are not part of this change.
