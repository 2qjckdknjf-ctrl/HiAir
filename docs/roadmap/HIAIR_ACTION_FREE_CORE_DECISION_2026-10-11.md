# ACTION free core decision — 2026-10-11

The owner asked to finish the updated development plan. The reconciled 2026–2027 ACTION plan requires at least one trustworthy Best Time for free users. Implement that requirement through the existing activity-plan endpoint: authenticated owned profile/place, same deterministic scoring, one recommended window, no fabricated data. Premium keeps the full forecast, alternatives and advanced insight endpoints. Store products, prices and cryptographic verification remain unchanged.

A missing recommendation remains missing, and severe/current safety information stays free. A free response must not expose a full hourly/alternative forecast. Existing paid clients receive the existing full contract. API ownership/entitlement/error regressions and both mobile clients must pass before deployment. This is one additive ACTION slice, not the AMBIENT/ROUTES/TWIN/HOME releases.

Native calendar export is accepted as a local ACTION completion: present the system event editor with explicit user confirmation, no calendar ingestion or server persistence. Reuse Protected Day events for action acceptance; no new plan lifecycle database is justified by this export.
