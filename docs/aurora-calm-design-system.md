# Aurora Calm / HiAir V2 design baseline

Mobile screens use `HiAirV2Theme` (iOS) and `V2Ui` (Android):

- Dark aurora gradient backgrounds
- Card containers with soft stroke
- Accent cyan/teal gradients for primary actions
- Secondary muted text `#A6B6D2` / `HiAirV2Theme.secondaryText`
- No fake dashboard numbers — loading skeletons and honest empty/error states

Onboarding and dashboard follow the same V2 visual language on both platforms.
